# 赛季地图分层素材 v1

本目录为素材包和独立审核预览，不接入正式导航、账号、战斗或奖励。
原始三张地图保留在上一级目录，没有覆盖。

## 查看

用浏览器打开 `preview.html`，可切换三张地图，查看建筑轻微放大、底图以及透明素材。
页面直接读取同目录图片，不需要启动服务器，也不需要连接网络。

## 文件清单

| 区域 | 地形底图 | 独立透明建筑 |
| --- | --- | --- |
| 山地关隘 | mountain/background.png | inn.png（驿站）、gate.png（关隘）、ruins.png（遗迹） |
| 河口古城 | river/background.png | town.png（城镇）、market.png（集市）、warehouse.png（仓库）、docks.png（双码头及船只） |
| 森林补给区 | forest/background.png | camp.png（营寨）、granary.png（粮仓与农田）、lodge.png（林间驿舍） |

共 3 张 RGB 地形底图、10 张 RGBA 透明建筑图。底图为 1448 × 1086。
建筑由内置 imagegen 基于对应原图独立重建与去背景，保留古代武侠、Q 版手绘和适中细节；不保证与源图像素级一致。
码头与船只为一个交互组；粮仓、农田与相关围栏为一个交互组。
河口地图最左侧的小渡亭和石桥保留为底图装饰，不属于独立建筑。

## 坐标与使用

`manifest.json` 提供各建筑 PNG 尺寸、主体边界、叠放位置及缩放锚点。
坐标使用 1448 × 1086 底图像素空间，页面应整体等比缩放。
`frame` 为包含透明留白的整张建筑图片显示框；`anchor` 为建筑底部中心，使用 0–1 的相对坐标。
`content_bounds_alpha_gt_200` 为 alpha > 200 的主体边界，仅用于校准尺寸，不是最终点击轮廓。
默认悬停缩放建议 1.05 倍。

位置是经过合成预览检查的初稿。正式接入时仍需按建筑轮廓制作点击区域，避免透明留白截获相邻点击。
`preview.html` 的整图矩形按钮仅用于素材校样，不代表正式玩法交互方案。
`placements-draft.json` 保留源图目标区域，便于后续调整。

## 生成与验证

- 生成方式：内置 imagegen；完整提示词见 `generation-prompts.json`。
- 已检查 3 张底图尺寸，以及 10 张建筑的真实透明通道和非空主体。
- 已在浏览器中查看三图合成，检查地图切换、素材加载及窄屏横向溢出。
- `review-*.png` 为浏览器渲染的叠放校样，不用于替代可交互图层。

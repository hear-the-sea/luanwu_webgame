# 赛季资源经济重设计草案

状态：方案已实现，运行参数位于 `data/season_campaign.yaml` 的 `resource_economy` 快照。原预算保留用于校准，默认值不代表真实玩家实测平衡。

## 1. 当前存在的问题

核查 `economy.py`、`activities.py`、`supply.py`、`rallies.py` 及 `data/season_campaign.yaml`：

1. 五类普通护院及铁骑补充均只消耗粮草，木材和铁料主要用于维修，长期缺少稳定需求。
2. 后勤、募训直接乘1—6级。单人满级普通兵理论产能8640/天，对比个人总领兵额度1200/天；实际会因库存、粮食和容量停产，和平期更容易堆满资源。
3. 人口档位在人数跨档时突变，不能平稳对应每多一名参与者所增加的需求。
4. 标准运输固定混装300粮、150木、100铁，不对应目的地真正缺什么。纯消耗NPC订单会鼓励用公共库存换个人贡献。
5. 破城推进没有木铁消耗，但维修需要付费；攻守都没有完整的军械资源循环。
6. 每次占领凭空补300粮，反复易主可以制造资源；当前占领也会重置当地库存，需要改为清楚的实物归属规则。

## 2. 三种资源分工

| 资源 | 主要来源 | 长期消耗 | 战时消耗 |
| --- | --- | --- | --- |
| 粮草 | 基础后勤、粮草讨伐、粮仓加成 | 训练普通护院与铁骑 | 行军、被抽中的战斗、驻防、商队运营 |
| 木材 | 基础后勤、林地讨伐 | 军械和训练物资 | 实际拆城、城防维修 |
| 铁料 | 基础后勤、遗迹讨伐 | 普通武备，铁骑消耗更高 | 攻城器械、城防加固 |

不新增资源种类。个人军资负责商店兑换，不允许从公共资源直接兑换。建设值负责自动设施/科技进度，仍不允许玩家手动乱花公共库存升级。

## 3. 用参与规模推导产出

令N为平滑后的经济有效参与人数；首次分组参考已完成有效任务的人数，后续每日按 `N今日 = 0.75 × N昨日 + 0.25 × 当前有效人数` 平滑。仅报名、空派遣和失效任务不计人数；0人阵营停止新增产出，已有库存不删除。分组前完成的有效任务可以用于首次人数评估，防止开服100人却只按第一个登录者发后勤。

每日基础产出（未计PVE、据点加成）：

- 粮草：(500 + 600N) × 后勤倍率。
- 木材：(300 + 350N) × 后勤倍率。
- 铁料：(200 + 250N) × 后勤倍率。
- 后勤1—6级倍率：1 / 1.12 / 1.24 / 1.36 / 1.48 / 1.60。

阵营首次开仓的一次性补给为粮草800+1600N、木材500+900N、铁料300+700N；后续人数变化不重复投放整份初始补给。

每5分钟结算，小数累计后发整单位，避免低人口被每次截断。N的变化同时影响产能和合理储量；现有超额库存不销毁。基数给少人阵营适度余量，单位参与者新增产出保持平滑。

### PVE为主动补充

| 任务类型 | 粮草 | 木材 | 铁料 |
| --- | ---: | ---: | ---: |
| 粮草讨伐 | 600 | 60 | 30 |
| 林地讨伐 | 80 | 420 | 40 |
| 遗迹讨伐 | 80 | 40 | 360 |
| 港口/NPC辎重混合任务 | 240 | 130 | 110 |

两个粮草建筑可以保留不同难度、贡献及行军距离，但按同一资源基准定价；不能让同难度建筑在贡献和资源上全面优于另一建筑。

每天前4次物资任务全额，第5—6次50%，之后不再产出阵营物资。讨伐与NPC辎重共用此收益档，防止更换玩法绕过；探索独立维持每天最多2次少量物资，不占完整讨伐物资档，避免侦察玩家牺牲一整次高收益PVE。探索主回报仍为有效情报，重复侦察无奖。失败给正常物资的25%，也消耗当次物资收益档。每日12次总出征及贡献日上限继续保留。收益档需要在发兵时预留，未交战的失效任务归队退回，不能按最后结算顺序恶意挤占。

情报仍提供一次20%物资加成。平衡预算不依赖据点和情报加成，玩家没有城池也应能运转。重复持有同一情报不产生资源。

标准资源日为“2次粮草 + 1次林地 + 1次遗迹”，每人获得1360粮、580木、460铁。这是预算情景，不强制每个玩家固定执行；阵营成员可分工。

## 4. 训练有资源成本，也有产能上限

| 每训练100名 | 粮草 | 木材 | 铁料 |
| --- | ---: | ---: | ---: |
| 五类普通最高阶护院 | 600 | 150 | 150 |
| 满科技嗜血铁骑 | 1000 | 400 | 600 |

按10人小批训练，所有成本为整数，只对实际完成训练的数量扣费。普通兵五种同基础成本，避免人为制造便宜的唯一最优兵种；不同战斗角色的进一步价格应在实测后调整。

- 普通兵每天最大补充 `200N × 募训倍率`，为五类兵种合计，不能每个兵种都拿一份额度。
- 募训1—6级倍率：1 / 1.15 / 1.30 / 1.45 / 1.60 / 1.75。
- 普通兵初始投放400N，总存量目标600N；五类均衡初始化。
- 总存量计算“公共兵库 + 已出征且存活的护院 + 已扣费训练队列”，不因出征后仓库变空再自动补一整库。
- 普通训练优先补近期真实战损，同时保持五种基础存量；没有缺口就暂停，不为了消耗资源无限造兵。
- 铁骑每天最多补充10N，总存量目标50N；只允许营寨拥有方训练，仍需三种资源，保持赛季专属满科技。
- 普通兵、铁骑的归还不重复扣资源、不返还训练成本；仅幸存兵回库，实际阵亡才产生补兵需求。

经济上限与1200/人/天领兵上限分开：领兵限制公共兵库的调用权，训练限制阵营能够恢复多少真实战损；反复借还不能改变存量目标。

## 5. 战时费用按实际行为发生

| 行为 | 建议成本 | 扣除位置 |
| --- | --- | --- |
| 行军 | 每100护院每10分钟4粮，按实际行军时间结算 | 公共库预留，未使用部分退回 |
| 普通驻军 | 每100人每小时8粮 | 当前驻防据点 |
| 铁骑驻军 | 普通兵3倍 | 当前驻防据点 |
| 真实交战 | 普通护院每100人每波3粮，铁骑3倍 | 进攻公共库；防守当地据点 |
| 商队运营 | 每趟5粮 | 公共库，归队后按任务实际状态结算 |
| 拆除100实际城防 | 木80、铁50 | 攻方预留军械；只按实际推进扣除 |
| 修复100实际城防 | 木120、铁60 | 防方当地库存 |

仅门客探索、讨伐不收费，确保缺粮时可自救。运输的5粮是运营费，不是从货物中暗扣；战报分别展示。驻防计时、行军计时和每波作战费对应不同活动时段，不对同一段时间重复收两份维持费。预留与最终实际扣费必须区分，返程费用要预留，不能断粮后让回家队伍永久卡住。

未被抽中的驻军不扣每波作战费，但仍付驻防维持费。无效攻击、已被友军占领、已修满等状态不扣未发生的消耗。控制进度阶段不再重复扣拆城器械，避免“同一面墙”付费两次。先校验资源支付能力，再提交对应城防变化。费用按实际进度比例取整，不能多次提交1点进度而免除成本。费用按整支集结军的总行为计算后分摊，不能每位玩家各收整队费用。

驻军缺粮仍安全返程，不照搬饥饿死亡。粮食不足时普通训练和铁骑训练分别暂停；公共库预留6小时已知驻防需求及已承诺任务的口粮，铁骑和非必要新行动不能抢占保底。

## 6. 运输由真实需求生成

- 每趟运输最多1200单位货物，不再固定混装。目的地需求为“当前驻军未来6小时口粮 + 当前实际城防缺口对应维修材料 − 本地库存 − 在途补给”。
- 本地已有维修材料不重复下单；没有驻军且没有城防缺口时，不为未来无限驻军预先刷粮。
- 先预占需求，再装载货物；多人运输同一目标不会重复计算缺口。
- 只给实际需要且实际送达的货物贡献。资源不同价值及需求由订单权重计算，不能按原始数量把低价粮草当高价铁料刷同等价值。
- 删除纯消耗公共资源换贡献的NPC订单。没有前线需求时做探索或讨伐，NPC辎重PVE保留。
- 拦截仍只转移30%的真实货物，余货归原队；转移不是全服新增资源。运营预留粮与任务货物分开存放、退款及记录。
- 新占领不凭空发300粮；已有当地资源随据点归属保留。占领保护期用于安排首批运输，玩家驻军前展示最低粮食需求。

## 7. 建筑收益与储备边界

- 前线粮仓：公共被动粮产+10%，不增幅PVE与掠夺。
- 渡口：运输载重+20%，提高物流效率。
- 林间营寨：开放铁骑训练。
- 青石关：通路、战果和前线位置；古城：高战果与周末争夺，无须每座城都增加资源倍率。
- 未来新增资源加成合计最多15%，不做资源、训练、科技三重乘算。
- 公共仓库容量为“3 × 标准日收入”，标准日收入用该日N和后勤等级计算，不取玩家实际刷怪数；折算标准日含每人4次基准PVE。
- 据点库存按6小时口粮需求及当前最大维修量确定，不作为第二座无限公共仓库；超额及需求变化按可核对的退款规则返还原阵营。
- 和平时2—3天资源到达储量上限是有意设计。已满时提醒参与争夺或暂停溢出生产，不制造无意义任务要求玩家烧库存。

## 8. 中期样本预算

假设N=10、后勤与募训3级，每人每日执行标准4次资源任务，无据点及情报加成，全部成功。每日来源：

| 来源 | 粮草 | 木材 | 铁料 |
| --- | ---: | ---: | ---: |
| 自动后勤 | 8060 | 4712 | 3348 |
| 主动资源任务 | 13600 | 5800 | 4600 |
| 合计 | 21660 | 10512 | 7948 |

中度交战样本的人均实际损耗及支出：普通护院阵亡220名、铁骑5名；推进200城防、修复200城防；运行粮173。运行粮为驻防32、行军76、交战60、运输5，按场景累计。假设本方拥有营寨且库存足以派出50名铁骑；这不是每人每日保证领取50铁骑。

一组可行行动额度为4次PVE、2次进攻/破城、1次驻防、1次运输、2次维修及1次探索，共11次；额外探索收益未计入收入。人均调用两次400护院进攻及一次300护院驻防，共1100名，低于每日1200领兵额度；驻防按单次一小时计算，遵守现有驻防时限。军务时长为离线可推进队列时间，不代表连续在线操作时长。

| 全阵营开支 | 粮草 | 木材 | 铁料 |
| --- | ---: | ---: | ---: |
| 普通兵补充2200名 | 13200 | 3300 | 3300 |
| 铁骑补充50名 | 500 | 200 | 300 |
| 驻防、行军、交战与运营 | 1730 | 0 | 0 |
| 拆除2000城防 | 0 | 1600 | 1000 |
| 修复2000城防 | 0 | 2400 | 1200 |
| 合计 | 15430 | 7500 | 5800 |
| 净结余 | 6230 | 3012 | 2148 |

普通补兵2200低于3级产能2600，铁骑50低于100；三种资源消耗约收入的71%—73%，保留约四分之一用于下一场大战。人口100时大体同尺度，不在19/20、99/100人处发生跳变；单人因固定补给部分获得适度余量。

强度敏感性：同一10人阵营每人只完成2次资源任务时，来源为14860粮、7612木、5648铁，维持上述战斗强度会每天缺570粮、152铁。这说明低任务参与不能同时维持高参战率，但可以减少损耗、调整任务类型或由其他成员补给；并非要求所有人每天固定刷4次。

高烈度情景按人均阵亡450普通兵、10铁骑、更大拆修量计算，补回全部损失的日需求为32000粮、14750木、11650铁，超过当日来源；且普通补兵需求4500也超过3级产能2600。此时要消耗已有兵力与物资、减少多线行动或休整。预算中的超产能需求不能当成已扣费、已生产的实际消耗。

没有战争的和平情景，普通兵从400N补到600N后停产，资源可以逐步满仓；不存在为获得建设值而强制让所有人制造无效消耗的需要。

## 9. 衡量“科学”的方法与落地顺序

先做可回放、可对账的来源/消耗分类，再依据实际玩家行为校准。当前预算使用假设场景，不能代替战斗强弱差异、真实在线人数及数据库并发测试。

建议观测：分资源的24小时真实净流入；库存可支撑当前战争的小时数；缺粮撤军率；各兵种实际阵亡与补充速度；PVE物资任务完成数分布；运输真正满足的需求；溢出产量；每名玩家使用公共资源与有效贡献的分布。正常交战初始目标为消耗70%—90%来源；完整普通兵储备在停战后约2—3天恢复；每位参与者维护同等驻军的资源压力不随人数档位突变。

账本应满足：全服库存变化 = 定额初始补给 + 有效生产 + 任务产出 − 训练与行军/战斗/维修消耗 − 明确记录的其他销毁。公共库、当地库存、在途货物、已实际扣库的生产预付款分别计入实物；仍包含在原库存里的预留只是不可用余额，不能重复计入总量。占领、运输、返程与拦截原则上只转移归属或位置。到达上限的未接收产量独立计溢出，退款和幸存者不能因上限被吞。

落地分三批：先改计量与三资源训练成本/产能/目标存量；再接行军战粮、按进度拆修和订单运输；最后增加建筑经济效果、容量与平滑人数。旧库存、在途费用快照、领奖记录保留；只按新规则处理后续产消，老任务按出发版本结算。已实现：0252增加阵营经济余数、补兵进度及资源账本；旧快照缺少开关继续原行为，新任务冻结费用及物资收益档，旧队伍不追溯收费。

最初配置草案见 [season_resource_economy_proposal.yaml](season_resource_economy_proposal.yaml)（历史提案，不作为运行入口），可复核的1/10/100人、等级1/3/6与任务参与敏感性结果见 [预算数据](../reports/season_resource_budget_20261025.json)。

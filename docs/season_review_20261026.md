# 赛季玩法复核（2026-10-26）

本轮结论：资源收集、前线补给、攻城、驻防、拦截已形成不同用途，但自动维修与小服进攻节奏、低成本驻军贡献仍有平衡风险。不能用功能测试通过代替长期平衡验证。

## 已修正的问题

| 问题 | 修正行为 | 目的 |
| --- | --- | --- |
| 长驻军出发带足全程粮草，运输需求很少 | 按用户确认，只预带首小时口粮，剩余由城内粮草及后续运输支持 | 让长期驻防真正需要后勤；旧在途费用快照保留 |
| 一小时驻军也按未来六小时预留补给 | 按剩余驻守时间计算，最多预备六小时；在途驻军按冻结驻守时长计算 | 不制造虚假需求，不重复扣除随军粮、当地储备及在途货物 |
| 公共粮草保护与当地运输需求口径不一致 | 共用驻守时域和冻结消耗单价，显式传入结算时间；无兵不产生普通护院粮耗 | 避免过度锁定公库粮草、影响生产或调剂 |
| 结算延迟时缺粮驻军仍能领取全程贡献 | 计算实际断粮时间，先结算口粮再结算驻守贡献；缺粮返程 | 不让离线扫描延迟产生免费驻守时长 |
| 后来的运输可能追补过去的断粮时间 | 交付货物前先清算当地驻军历史消耗，断粮记录不可恢复；未使用货物退回 | 不用新物资追溯兑换过去贡献 |
| 驻守贡献未计入有效活跃 | 统一识别正向贡献凭据及兼容的旧流水，报名与经济人口复用 | 真正驻守的玩家也支持阵营产能；零贡献不计入 |
| 零有效贡献战斗也可能满足周对抗条件 | 周对抗日要求正向有效贡献，达到每日上限但有真实有效表现的请求仍有效 | 不靠空战报解锁周胜点；已结算周不追溯 |
| 古城周日合法抵达、周一才扫描时被误判 | 以该波计划抵达时间判断周末窗口；派遣及集结加入仍提前校验 | 延迟结算不惩罚合法行军，后续波次不无限继承周日资格 |
| 仓库满仍展示无条件收益 | 显示满仓或仓容不足提示，行动建议避开无物资收益的收集 | 不让玩家浪费门客次数而不知原因 |
| 门客次数已用完还推荐派遣 | 指引改为查看队伍，禁用无法实际加入的集结 | 建议与真实可操作状态一致 |
| 周胜点规则没有说清最终资格 | 周规则补充双方至少三天有效对抗的赛季胜方条件，天数读取配置 | 区分周胜点与赛季胜方资格 |
| 探索者返程后难以赶上30分钟情报有效期 | 按用户确认延长至2小时；迁移仅替换进行中赛季旧默认1800秒 | 间歇在线玩家也可自行利用；自定义时长和已有情报不追溯 |

本轮复用现有出征结果、贡献账本、资源需求与返程流程，没有新增表结构、手动升级入口或玩家额外操作。0265仅为情报配置的数据迁移。

## 玩家行动应当有的区别

| 行动 | 阵营实际收益 | 适合何时进行 |
| --- | --- | --- |
| 资源收集 | 从外部获得粮木铁，推进自动建设 | 公库缺资源、兵力补充不足；最稳定的发展入口 |
| 探索 | 共享目标守备情报，并给后续同区域收集一次额外收益 | 需要攻城情报，或队友准备接续资源收集 |
| 攻城 | 消耗守军、箭塔和城防，取得据点功能、占领战果及后续持有战果 | 能组织接力，且公共战备足够 |
| 驻防 | 为敌方进攻提供真实防线；按实际驻守时间获得贡献 | 需要保护功能建筑或等待队友接防 |
| 运输补给 | 将公共资源送入城内，支持驻军吃粮、城防维修 | 己方据点有真实需求；运输不是额外造资源 |
| 拦截运输 | 胜利转移全车最多30%的物资，同时减少敌方当地补给 | 敌方有值得争夺的真实运输队，能在窗口内抵达 |

运输与收集不能只比较“新增多少物资”：前者把已有资源变成城内守军续航和城防恢复，后者新增公库资源。拦截同时削减敌方前线供给，但小订单的纯资源收益可能低于收集，不应承诺任何一趟拦截都优于PVE。没有敌方运输时不伪造目标，也不要求玩家必须完成拦截任务才能发展。

## 约20名玩家时的资源预算

按双方各10名有效活跃、基础等级、不开额外据点增益估算，单阵营每天：

| 项目 | 粮草 | 木材 | 铁料 |
| --- | ---: | ---: | ---: |
| 被动产出 | 6,500 | 3,800 | 2,700 |
| 普通护院10,000名的募训成本 | 60,000 | 15,000 | 15,000 |
| 铁骑1,000名的募训成本（须拥有营寨） | 10,000 | 4,000 | 6,000 |
| 满基础日产能与被动产出的差额 | 63,500 | 15,200 | 18,300 |

约10次粮草收集、5次木材收集、5次铁料收集的全额基础收益为72,000粮、24,000木、21,000铁。平均每名活跃玩家两次收集，理论上可支撑该基础募训规模，并有少量战备空间。

这是生产预算，不是实际承诺：每日收益档、仓容、战斗结果、科技等级、库存目标、铁骑是否解锁及玩家是否参战都会影响结果；额外战斗与持续补给需要额外资源。募训消耗远大于被动产出这一目标已满足。人数档位回归覆盖少人情况，但没有完成20名真实玩家长期在线试玩或MySQL并发压测。

## 尚需平衡决策的事项

1. **城防回血可能抵消分散攻击（高优先级）。** 满血关隘150万、箭塔10万，维修每30分钟最多10万城防血量。此前本地样本三名较强门客带750普通护院，八普通回合对满塔目标约造成16万城防伤害；这一小样本不代表全服。若队伍一小时才来一波，自动维修可能消掉进展。保持用户指定血量，建议下一步用双方各3至5名真实参战者校准“接力进攻每小时伤害”和“维修每小时回复”，再决定是否只在实际交战后短暂暂停维修。每名门客两次不等于每名玩家两次，玩家可以换门客，测算不能混淆两者。
2. **无战事驻军贡献可能成为最省力选择。** 当前8小时80贡献，带极少或不带护院也能获得时长贡献；同一玩家一天两次长驻防可达160，而收集四次全额、两次半额基础贡献约150。建议后续确认一个“无战斗驻守贡献独立日上限”，或者根据实际驻防兵力给予档位系数。不能只提高PVE奖励来掩盖，也不在未确认时改变已有每小时10贡献的约定。
3. **探索的使用提示还可更直接。** 用户已确认延长至2小时，窗口矛盾已修复。当前加成仍是同阵营、同区域、一次性共享，不能理解为每名玩家各有一次；后续可在区域资源收集入口显示剩余时间与是否已使用。
4. **周末古城具有持续持有优势。** 古城只允许周末争夺，工作日仍按持有产生战果。这是当前规则的真实效果，会放大周日最终占领的重要性；是否仅周末计分属于玩法决策，暂不变更。
5. **军需调剂入口与服务权限需统一。** 当前集市界面只向占领方展示货摊/调剂，旧服务仍允许非占领方使用基础调剂比例。用户明确要求占领后才能看货品，货品权限已一致；非占领方是否还保留基础调剂，应另行明确，不能把商品隐藏当成调剂权限校验。
6. **后入季玩家的终极奖励预期。** 自选召唤卷轴需要3,000贡献，每日最多300，理论最少十个贡献日。赛季剩余时间不足的玩家不应被提示一定能拿到终极奖励；个人已达标奖励仍可领取。

# 演武台

竞技场新增“演武台”页签，开放青龙擂、白虎擂。两张配图由内置 image_gen 工具生成，存放在 `static/images/buildings/`，与项目现有古风建筑插画风格保持一致。

页面去掉重复标题，压缩奖励与擂台卡片间距；参战和调整阵容使用弹窗，沿用个人任务、踢馆出征的门客卡片及护院数量控件。采用项目已有通用弹窗控制器，避免原生 dialog 在手机上的显示兼容问题。支持全选（至多二十名）、清空、数量增减与直接填写。

护院展示统一按箭、拳、枪、剑、刀、探子排序，同类由低级到高级；战报阵容、每回合剩余护院、演武台配兵及阵容查看共用排序规则，战斗行动日志保持原有发生顺序。战报反伤文字和门客名称完整换行，主目标闪避时仍显示触发技能，额外目标的状态效果按命中顺序逐目标展示；回血与同单位其他被动合并时保持触发先后，原始战斗日志不变。损失明细及帮派出征护院也沿用统一排序，配置刷新会同时清理排序缓存。

## 玩法

- 门客最多二十名，玩家自由勾选自己的非重伤门客。阵容以满血快照参战，报名与战斗均不改变真实门客状态，不产生实际伤害；后续属性变化不影响已保存的快照。
- 临时规则：可选择任意已有兵种、无需实际持有，但护院总数必须不超过所选门客带兵额度之和。旧版超额守擂快照在战斗和展示时按快照带兵上限同比缩减。列表仍展示庄园与钱庄合计持有量。上阵不扣库存，战斗无实际损失。
- 护院应用所选门客的器械加成及满级战斗科技加成（仅限演武台，不升级真实科技），攻守双方规则一致。器械与门客属性保存于阵容快照；已有守擂快照的战斗科技也按满级生效。
- 空台可直接登台，挑战胜利后用攻擂阵容接任；平局留任，不增加成功守擂次数。每人同时占一台，每任最长两小时，下台后十分钟内不可再次占据原台。
- 对战结束后，擂主可更新门客和护院阵容，新阵容用于下一场。换阵不限制次数、无换阵冷却，不重置任期、守擂次数及连胜。对同一任擂主，每名攻擂玩家最多挑战两次，两次挑战间隔十分钟；更换擂主或产生新任期后重新计算，已有对战计入本任次数。正在结算的战斗与更新阵容通过同一事务锁串行处理。

## 收益与查看

- 每累计十分钟守擂得四枚角斗币，每日时间收益上限一百二十枚；当日多任累计，零头和跨日时间分别结算。
- 有效守擂胜利得二十枚角斗币，每日前十次；有效挑战参与得十枚，每日前五次；每日最多主动挑战十次。基础三项每日最多三百七十枚角斗币，含连胜与终结奖励共最多七百枚。
- 奖励连胜达到三、五、十次时，分别额外得三十、六十、一百二十枚角斗币，各档每任只领一次；连胜奖励每日最多二百一十枚。同时追加春秋币三／六／十二枚，每日最多二十一枚，沿用有效连胜资格并自动入仓库；终结连胜不追加春秋币。春秋币每日额度通过既有操作凭证统计。
- 击败擂主终结连胜时，按其奖励连胜已达到的最高档额外得三十、六十或一百二十枚；终结奖励每日最多一百二十枚。平局、换阵保留连胜，换任重新累计。同一对玩家当日重复对战不计奖励连胜，也不发终结奖励。每日限额通过既有资源流水统计，跨任期、跨擂台共用，无新增数据库字段。
- 同一对玩家每日仅首次对战发放胜场及参与奖励；交换攻守角色、改换擂台不重置奖励资格。
- 查看对方阵容每次购买付二十万银两，系统扣两万手续费，对方实收十八万。购买绑定擂主及阵容版本；状态变化拒绝扣费，重复请求不重复扣费。
- 付款前先按庄园既有规则结算尚未入账的产出，再校验余额并扣款；到账产出可用于本次支付。
- 买家可查看当次购买的阵容快照，刷新购买记录不重复付款；后续换阵不更新旧购买记录。自己的阵容可免费查看。
- “赛事查看”按青龙擂、白虎擂归并为两条可展开记录。每台独立分页（每页十任），显示最近二十四小时内的守擂时段、擂主、获胜次数及战报入口，分页保持对应擂台展开；观众可查看当前任期与历史战报。战报沿用既有展示，不增加损失标注。
- 天下布武、围攻光明顶与擂台赛事在结束后保留二十四小时查看，历史列表及擂台战报列表支持分页。个人既有战报归属权限保持原规则。

## 接入与验证

核心服务：`gameplay/services/arena/ring.py`。规则：`data/arena_ring_rules.yaml`，可通过既有运行期规则刷新入口清理缓存。后台任务 `gameplay.scan_arena_rings` 每分钟结算时间收益并结束到期任期，进入既有 timer scan 队列。

迁移 `0197_arena_ring` 建立擂台、任期、战斗、每日统计、幂等操作及购买记录，并初始化两座擂台。迁移依赖项目当前的 `0196_equipment_output_bound_quantity`。本次只在独立测试数据库验证迁移，没有改动实际游戏数据库；部署时需按项目现有流程应用迁移并加载新任务调度。

回归覆盖：真实战斗中的双方科技与器械加成、超过十名门客、虚拟配兵及真实库存无损、换阵、奖励上限与跨日、同对手奖励、挑战次数、交易回滚、重复扣费、陈旧阵容拒绝扣费、购买记录隐私、观众战报与二十四小时边界、历史分页。另以本地 Chromium 检查桌面和手机布局及带兵额度与二十名门客上限。

## 管理员重置

管理员清空当前演武台时，结算已累计的时间奖励，结束当前任期并标记 `admin_reset`。同次操作将已有未结束的占台冷却标记为已清除；新占台及挑战忽略这类任期的冷却。保留历史结束时间、战报和已经发放的奖励，正常下台仍执行十分钟冷却。

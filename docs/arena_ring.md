# 演武台

竞技场新增“演武台”页签，开放青龙擂、白虎擂。两张配图由内置 image_gen 工具生成，存放在 `static/images/buildings/`，与项目现有古风建筑插画风格保持一致。

页面去掉重复标题，压缩奖励与擂台卡片间距；参战和调整阵容使用弹窗，沿用个人任务、踢馆出征的门客卡片及护院数量控件。采用项目已有通用弹窗控制器，避免原生 dialog 在手机上的显示兼容问题。支持全选（至多二十名）、清空、数量增减与直接填写。

护院展示统一按箭、拳、枪、剑、刀、探子排序，同类由低级到高级；战报阵容、每回合剩余护院、演武台配兵及阵容查看共用排序规则，战斗行动日志保持原有发生顺序。战报反伤文字和门客名称完整换行，主目标闪避时仍显示触发技能，额外目标的状态效果按命中顺序逐目标展示；回血与同单位其他被动合并时保持触发先后，原始战斗日志不变。损失明细及帮派出征护院也沿用统一排序，配置刷新会同时清理排序缓存。

## 玩法

- 门客最多二十名，玩家自由勾选自己的非重伤门客。阵容以满血快照参战，报名与战斗均不改变真实门客状态，不产生实际伤害；后续属性变化不影响已保存的快照。
- 临时规则：可选择任意已有兵种、无需实际持有，但护院总数必须不超过所选门客带兵额度之和。旧版超额守擂快照在战斗和展示时按快照带兵上限同比缩减。列表仍展示庄园与钱庄合计持有量。上阵不扣库存，战斗无实际损失。
- 护院应用所选门客的器械加成及满级战斗科技加成（仅限演武台，不升级真实科技），攻守双方规则一致。器械与门客属性保存于阵容快照；已有守擂快照的战斗科技也按满级生效。
- 空台可直接登台，挑战胜利后用攻擂阵容接任；平局留任，不增加成功守擂次数。每人同时占一台，每任最长两小时，下台后十分钟内不可再次占据原台。
- 对战结束后，擂主可更新门客和护院阵容，新阵容用于下一场。换阵不限制次数、无换阵冷却，不重置任期、守擂次数及连胜。对同一任擂主，每名攻擂玩家最多挑战两次，两次挑战间隔十分钟；更换擂主或产生新任期后重新计算，已有对战计入本任次数。挑战在短事务中固定阵容，释放擂台锁后模拟，最后重新锁定并校验版本、任期、期限及挑战额度；模拟期间换阵或换任时拒绝过时结果。战报仅随最终结算事务保存，失败或重复请求不会留下额外战报。

## 查看与记录

- 当前演武台不发放时间、守擂、参与、连胜或终结奖励，也不追加春秋币；每日最多主动挑战十次。历史奖励配置和统计字段仍供旧记录兼容使用，不能据此认定现行玩法会发奖。
- 查看对方阵容免费，不扣银两、不转账，也不触发资源结算。同一玩家查看同一任期的同一阵容版本复用已有侦察快照；后续换阵不改写旧快照。自己的阵容可直接查看。
- 同一操作凭证返回已完成的结果，不重复挑战或消耗次数。凭证保留到结果所属任期结束后的二十四小时；历史清理后，旧输入仍会因版本或任期失效被拒绝。
- “赛事查看”按青龙擂、白虎擂归并为两条可展开记录。每台独立分页（每页十任），显示最近二十四小时内的守擂时段、擂主、获胜次数及战报入口；单任战报每页三十场。列表仅读取展示字段，不加载战报的完整回合 JSON。
- 天下布武、围攻光明顶与擂台赛事在结束后保留二十四小时查看。个人既有战报归属权限保持原规则。
- 后台维护按表分批清理已结束二十四小时的擂台任期、侦察快照、操作凭证和挑战记录，保留当前任期及其凭证；每日统计保留十五天。战报本体继续沿用既有战报保留策略，清理擂台历史不会额外删除战报。

## 接入与验证

核心服务：`gameplay/services/arena/ring.py`。规则：`data/arena_ring_rules.yaml`，可通过既有运行期规则刷新入口清理缓存。后台任务 `gameplay.scan_arena_rings` 每分钟结束到期任期，进入既有 timer scan 队列。`gameplay.services.arena.ring_retention.cleanup_ring_history` 提供有界历史清理，由常规维护任务调用。

迁移 `0197_arena_ring` 建立擂台、任期、战斗、每日统计、幂等操作及侦察记录，并初始化两座擂台。迁移依赖项目当前的 `0196_equipment_output_bound_quantity`。本次只在独立测试数据库验证迁移，没有改动实际游戏数据库；部署时需按项目现有流程应用迁移并加载新任务调度。

回归覆盖：双方科技与器械加成、虚拟配兵及真实库存无损、免费侦察及快照复用、无奖励、挑战次数与冷却、事务外模拟与过时结果拒绝、并发同凭证幂等、失败无孤儿战报、二十四小时历史边界、清理保护及列表查询列。MySQL 锁并发用例须在独立测试库运行，SQLite 回归不能替代真实行锁验证。

## 管理员重置

管理员清空当前演武台时，不发放奖励，结束当前任期并标记 `admin_reset`。同次操作将已有未结束的占台冷却标记为已清除；新占台及挑战忽略这类任期的冷却。保留历史结束时间、战报和已经发放的奖励，正常下台仍执行十分钟冷却。

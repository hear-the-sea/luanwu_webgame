# 赛季玩法易懂性与必要性检查

核查对象为当前三资源经济与集结版本，依据实际服务端行为、配置及页面入口。以下区分“当前实现”和“建议变更”，不将建议当成已生效规则。

## 判断标准

每个独立行动应能回答：玩家什么时候需要它、消耗什么、实际改变什么、是否有另一行动用更低成本达到相同结果。胜负和个人成长也应分别说清楚：占领并持有据点产生阵营战果；有效参与获得个人贡献和军资。资源与兵力为争夺提供支撑，不是额外独立胜利条件。

## 当前最值得改的三处

1. **合并普通港口讨伐与NPC辎重。** 新版两者都在渡口，使用同一混合物资包、同一每日物资收益档、同节点NPC战斗、同等胜利贡献和建设值。NPC辎重的独立每日次数没有带来独特战略作用，反而增加一项要解释的限制。建议只保留“讨伐水匪/辎重”这一种港口PVE；旧NPC队伍继续结算，不删除数据。
2. **把攻坚与破城整合为一个玩家入口“集结攻城”。** 当前attack清守军后返程，siege另开一轮集结推进城防与控制；同一占领目标往往重复30分钟集结与配兵。建议单次集结按清军、拆城、占领自动推进，继续保持3门客、最多5玩家、最多等待30分钟、对等玩家人数车轮战、实际伤势/兵力和费用。不改变成败判断；仅减少玩家必须理解的行动类别。需要同步服务端派遣校验、波次状态、途中抢占/召回、旧attack/siege版本兼容和测试，不能只改按钮名称。
3. **解决粮仓PVE的弱选择。** 驿站和粮仓新版都给600/60/30物资；粮仓NPC基准25级、行军360秒，而驿站3级、180秒；粮仓胜利贡献25对驿站20不足以保证值得多承担风险。粮仓占领有+10%被动粮产，但这是阵营据点价值，不能证明重复的PVE按钮必要。建议粮仓专注可占领战略建筑、运输与驻防，普通产粮PVE集中驿站。若要保留粮仓PVE，则必须有明确独有收益与风险回报校准，优先减少重复入口。

## 保留行动及其必要性

| 玩家看到的行动 | 一句话作用 | 何时值得做 | 必要性 |
| --- | --- | --- | --- |
| 讨伐物资 | 给公共仓库补缺少的粮、木、铁 | 战备缺口、平时发展、缺粮自救 | 主动资源来源，单人、无对手也能参与 |
| 侦察 | 看清敌方驻军，避免盲目进攻 | 敌阵容未知、准备攻城 | 信息价值独立于战斗与搬运；有情报时不必每天硬做 |
| 集结攻城（建议统一入口） | 占据点、赚阵营战果 | 有兵有物资、需要争夺目标 | 直接决定阵营竞争目标 |
| 驻防 | 用真实队伍阻止敌方夺城 | 城池将受攻击、需要保护营寨/粮仓 | 保住战果与特殊产出，实际参战才能获战斗贡献 |
| 运输 | 把公共资源送到缺粮或缺维修料的城 | 系统有真实补给订单 | 公共有粮不等于城内有粮；供应驻军与维修 |
| 维修 | 花当地木铁修复被打坏的城防 | 城防确有损伤且有材料 | 增加敌方破城成本；满城不需要派维修队 |
| 拦截运输 | 夺取敌方在途物资并延误补给 | 确有敌运输队，且有可参战队伍 | 攻击对手后勤；与自产物资不同，属于真实转移 |

这些行动不要求玩家每天全部做完。侦察、运输、维修、拦截都应由当前局势触发，无相应需求时明确标注“暂不需要/没有目标”。NPC辎重不应被当成拦截存在的必要条件；无敌方运输时做其他军务即可。

## 页面还应怎么简化

1. **只给一个下一步建议。** 未报名先报名；已有部队先看军务；有急需补给先运输；仓库缺某资源指向对应PVE；准备战争先侦察/集结。提示必须来源于实际队伍、库存和目标状态，不能虚构威胁。玩家仍可自主选其他行动。
2. **每个弹窗先说明“作用—代价—结果”。** 例如“运送青石关需要的粮草，交付后维持驻军；本趟装载X，预计费用Y；未交付物资退回”。首次出征必须看见会扣真实门客生命、重伤及兵力损耗，不能全藏在长规则中。
3. **只展示当前可执行动作并解释不可用原因。** 没有运输目标说明“当前城内补给充足”；没有敌运输说明“暂无可拦截队伍”；城防满说明“无需维修”；进攻位在外说明“原队伍归队后可再出征”。无需让玩家先提交再碰业务错误。
4. **普通玩家只需认清三种量。** 阵营战果决定胜负；个人贡献决定里程碑/排名；军资用于商店。保留粮木铁明细在后勤和派遣所需场景，平滑人口、内部预算、资金流水、科技公式放详情。
5. **选择门客与配兵减负。** 提供“沿用上次有效配置/按容量配兵”后，仍展示本次门客、兵种、实际数量、费用和可用额度，由玩家确认派遣；不能默认自动消耗稀有铁骑或把重伤门客算可用。
6. **回报一眼可懂。** 行动完成显示“贡献+X，阵营粮草+Y/城内补给+Z，门客受伤N，护院损失M”，区分产出、转移和退款。每日物资四满两半与贡献上限用简短状态，不要求先算倍数。

## 本轮已处理的误导说明

- 新资源季的渡口不再提示可以接已经取消的“驿站订单”。
- 情报提示不再将“同一入口已有情报”错误解释为所有目标都不能继续侦察。
- 讨伐物资说明明确是全额基准，实际还受当日物资收益档影响。
- 后勤说明明确训练扣三资源，且受到补兵产能和包含在外兵力的目标存量限制。

上述文案修正不改变玩家现有资源、伤势、行动费用与在途状态。后续已按确认实现统一攻城、重复PVE合并、粮仓战略定位，以及仓库订单和集市军需调剂，见[精简军务规则](season_simplified_play.md)。快捷配兵与动态行动建议仍是后续可选优化。

## 仍需真实试玩验证

新玩家能否在不看全文规则时回答“现在应该做什么”；能否在一次往返后区分公共库与城内补给；是否理解攻城目标和个人奖励的关系；各军务的参与率、无效提交率、需要打开规则的次数。数值测试与页面检查不能替代真实新手试用。

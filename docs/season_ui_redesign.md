# 赛季界面简化

原界面在地图之前依次展示规模、规则、状态和操作，地图下又叠加集结、队伍、战线、排行榜及战报。新版以地图为主屏，按玩家当前意图区分信息。

- **战场地图**：保留比分、三张地图、建筑归属木牌；后勤、奖励、商店和队伍集中为常用入口。电脑侧栏、手机底部按钮组。
- **集结军务**：集中处理加入/取消集结、查看行军、驻防及召回。支持刷新链接与哈希定位返回。
- **站内邮件**：参战战报自动投递并附可点击战报，军务页提供邮件入口。
- **贡献排行**：查看本阵营贡献排名；排名奖励统一进入“赛季奖励”领取。
- **战局详情**：存放有效活跃、人口档位、共享情报、据点汇总、详细规则及历史赛季选择。

建筑弹窗只默认展开主要个人行动；多用途据点可展开另一套攻城集结表单。出征、驻防规则和科技等级按需展开，关键战况及操作按钮仍直接可见。所有派遣、领兵、战斗、资源、绑定奖励和满科技铁骑规则保持不变；服务端操作凭据与权限校验沿用原入口。

主视图和三个地图战区分别具有键盘方向键、Home/End导航。局部导航退出时清理事件和弹窗，返回重新初始化；军务刷新链接可以打开被折叠的对应主面板。地图保留透明轮廓点击、建筑放大、木牌及窄屏内部横向查看。

参考[莉莉丝《万国觉醒》官方介绍](https://ancient.lilith.com/cn/rok/introduce.html)中地图、探索与集结协作的玩法组织；这里的三个主视图与古风木牌布局是针对本项目的界面设计。

验证：37项相关后端回归、11项浏览器检查通过，覆盖报名、待分组、归档领奖、建筑弹窗、三图切换、实际归属、军务与键盘导航、哈希返回、窄屏溢出和局部导航。最终手机标题排布另做截图复核。

后续调整：已移除独立“行旅战报”页签；真实参战战报改通过站内邮件投递，军务页提供邮件链接。主界面仅保留地图、集结军务与贡献排行，原战报与参战权限记录保留。

## 地图信息整合

主屏取消右侧长栏，将比分、个人贡献/军资、里程碑与当周进度、常用操作统一收入地图边框。启用周制时比分优先显示最终胜负依据的周胜点，累计持有战果移至战局详情。

建筑复用木牌新增一条短提示：优先展示休战、可加入集结、真实补给缺口、本人在外队伍、保护、建议主攻或己方驻军人数；没有紧急状态时展示粮/木/铁讨伐等用途。同一建筑只选一条提示，不展示未侦察的敌军姓名和阵容。集市及古城已调整的木牌位置保留。

地图底部合并一条主攻和一条补给军令，点击直接打开对应玩法；移除长篇侧栏说明和重复操作卡片。详细规则、后勤账本、周奖励、配置阵容仍在原弹窗/军务页，玩法与消耗规则不变。桌面地图全宽，手机操作栏四列，军令上下排列，地图继续内部横向查看。

## 建筑弹窗简化

弹窗统一使用建筑缩略图、用途、建筑名称与归属作为页头，宣纸底色、木色边线与朱砂主按钮延续古代地图风格。

- 讨伐建筑直接显示三项基础物资收益、门客选择及出征按钮，单一玩法不再设置无用页签。
- 城池首先显示城门、箭塔血量与驻军概况；敌方默认集结，己方默认派遣，驻军名单及城内补给放在“守备”。休整期、缺料等影响操作的状态保留。
- 仓库按“补给、兵库、发展”分屏，产兵只显示日产与库存目标，建设只显示等级和进度，科技按需展开。
- 集市按“货摊、攻防、调剂”分屏，保留价格、限购、绑定状态、刷新时间、兑换结果和不可用原因，移除长篇结算规则。

门客气血、今日剩余出征次数、带兵上限、剩余领兵额度与基础行军时间保留。护院输入默认折叠，已选兵力始终可见。移除“上次配置”和“自动配兵”，由玩家手动选配护院。切换分屏不清空草稿，提交继续使用原有接口与服务端校验。

窄屏门客列表改为单列，弹窗内部滚动，出征按钮保持在面板底部；城防血量与物资收益采用紧凑数字区。移除重复规则、后勤公式和无关的操作说明，不改变战斗、资源、配额与奖励规则。

赛季派遣基础单程统一30分钟，沿用个人任务平均敏捷减时（每10点减少1%，上限50%），并保留关隘加成。界面移除伤损提示，配兵与兵库复用兵种头像组件。配置迁移只修改未结束赛季的后续派遣基础时间，不改在途队伍的既定时间。

集市未占领时仅显示攻防，服务端不返回货单、刷新时间与商品内容；占领阵营才有货摊与调剂页签。集市和阵营商店统一复用物品模板与仓库图标，礼包逐项显示图片和数量，缺少专属图片时显示通用包裹图。PVE行动更名为“资源收集”，地图用途同步改为粮草/木材/铁料收集。

渡口提供拦截与随队护送两个可选入口，分别列出敌方/己方运输队及双方报名人数、剩余时间。到达后军务状态显示“等待遭遇战”。隐藏模式的控件禁用，确保切换模式后只提交当前选择的车队。多人遭遇规则按需展开，说明不提前触发、最多5人、余货继续交付与未入场退款。

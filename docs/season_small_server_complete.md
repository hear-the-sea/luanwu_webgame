# 少人数赛季玩法完成记录

适用目标：全服约20名报名玩家，上线时间分散，常见每边同时只有1—3人。保留90天周期、前三天报名、前83天行动、最后7天归队领奖，地图全部开季开放，古城周六日全天开放。

## 玩家只需理解的循环

平时看阵营当前缺口，派一次物资讨伐；有队友集结就加入，没时间等可以明确授权一次预约；城防与控制进度由后续队伍接力。夺下建筑后按需要驻军、运输和维修。每周完成个人有效参与和阵营共同目标即可领奖，最终输赢不影响个人贡献里程碑和召唤卷轴进度。

## 周结算与兼容

`campaign.playability`统一配置所有新增规则，校验权重、档位、限额和奖励正数。旧快照缺此字段继续原分配、NPC和最终胜负算法。旧在途继续原NPC/伤势/兵力结算。

新周账本存于`SeasonFaction.economy_state.weekly_campaign`，记录启用时刻、旧积分和分周战果，不追溯更改启用前成绩。计分跨周时按各计分时刻划分，重复扫描不重复计分。贡献只读唯一`merit_credit`实际入账并写明发生时刻，避免展示战报双计；筛选先限定周次和日期，避免每次打开扫描90天全部记录。

预约复用`SeasonMember.lineup.reservation`，保留报名metadata；成功自动加入同时记`rally_join`审计以计入每日次数。逐条savepoint回滚失败扣款。周奖励及市场购买均复用赛季行锁、独立凭证和绑定发奖入口。

0253追加集市占领，0254追加少人协作配置。均不改变数据库表结构；保留成员、既有阵营、门客、库存、任务、已领记录及旧据点状态。现有赛季启用时从启用点开始新周账本，不补算以前未存在的周胜点。最后7天为归队领奖阶段，不提示新的参与任务。

## 质量边界

数值均可配置。验证覆盖20人分组与仅3人实际出征、旧在途、预约原子回滚、单人/双人/NPC接力、真人守军不缩放、跨周和尾声、奖励绑定/幂等、地图与手机操作。不能把自动化测试等同于真实20人长期平衡结果；上线后应观察集结等待、失败原因、双方有效参与、贡献获取速度和活动分布，再根据真实数据调值，不提前增设新任务。

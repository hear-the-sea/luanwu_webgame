每季 {{ campaign.duration_days }} 天，前 {{ campaign.registration.days }} 天集中报名，按声望、近期有效参与及可出战门客实力平衡分组，兼顾上线时段。已有门客不受阵营限制；每次出征重新选择空闲门客，无固定赛季阵容。{% if guest_daily_limit %}每名门客每天最多 {{ guest_daily_limit }} 次赛季出征，各行动共享额度；一轮车轮战只计一次。{% endif %}

门客使用真实血量并受伤、重伤，按个人任务规则治疗与恢复。护院由阵营后勤生产，出征实际占用公共兵库，阵亡消耗、幸存者返程归还，不消耗庄园护院。

每人最多同时派遣 {{ max_expeditions }} 支队伍，每日领兵额度 {{ daily_troop_quota }} 人；单队仍受所选门客的带兵能力限制。派遣包含行军、执行与返程，驻防队离线也会迎战，召回保留已发生战损。

PVE、运输、攻城及成功防守累积阵营建设值，达到门槛后自动提升后勤、募训及科技，不消耗公共资源，也不受赛季天数限制。青石关日常争夺，河口古城{{ siege_schedule_label }}；驻防、运输与拦截都使用实际派出队伍。{% if coalition.enabled %}{% if simplification.enabled %}集结攻城一次推进清军、拆城与占领，每波双方各最多{% else %}攻坚和破城需同阵营集结，每波双方各最多{% endif %} {{ coalition.max_members }} 位玩家，每人最多 {{ coalition.commander_guest_limit }} 名门客；守方按攻方人数抽选，未选驻军待命。攻方获胜后带剩余血量和兵力进入下一波，不自动补满。{% endif %}

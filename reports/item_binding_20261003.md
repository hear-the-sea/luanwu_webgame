# 道具绑定功能与发放方式

本文记录已上线的首版功能。后续装备图纸、春秋币兑换及宝箱规则调整见 [item_binding_rules_20261003.md](item_binding_rules_20261003.md)，该调整当前尚未部署。

## 后台发放绑定洗髓丹

进入后台的“全服邮件活动”，在“绑定附件道具”填写：

```json
{"xisuidan": 10}
```

保存、发布活动后，玩家领取附件获得 10 个绑定洗髓丹。沿用现有全服邮件收件人规则，排除虚拟玩家，并通过活动收件记录及附件领取状态防止重复发放、重复领取。

普通附件道具与绑定附件道具可以同时填写，同一键可以分别发放。底层附件格式示例：

```json
{
  "items": {"xisuidan": 3},
  "bound_items": {"xisuidan": 10}
}
```

旧邮件的 `items` 仍按非绑定发放。开发验证阶段没有实际发放道具；随后按用户授权完成上线与发放，记录见末节。

## 道具配置与库存

- 保留原道具键，例如 `xisuidan`，无需复制绑定版道具模板。
- 模板新增 `default_bound`，默认为 `false`。可在道具后台或 YAML 中配置 `default_bound: true`，影响采用模板默认值的后续入库，不改变已有库存。
- 库存 `quantity` 表示总数量，`bound_quantity` 表示其中绑定数量；非绑定数量为二者之差。数据库约束绑定数量不能大于总数量。
- 发放接口可显式覆盖模板默认值：`add_item_to_inventory(manor, "xisuidan", 10, is_bound=True)`；非绑定使用 `is_bound=False`。
- 旧库存、旧装备以及已有生产队列默认为非绑定。仓库展示绑定与非绑定数量。

## 限制与使用

- 禁止绑定道具出售给系统商店、交易行上架、参与拍卖支付、帮会捐赠及藏宝阁转移；掠夺只取非绑定库存。
- 自用优先扣绑定数量，普通库存保留；冻结金条仍不能自行消耗。
- 装备穿脱、替换和强制卸下保留绑定状态。开箱、合成、锻造、分解及冶炼产生的道具继承所用绑定道具或绑定材料的状态。
- 绑定装备暂不能用作募兵材料：现有护院阵亡回收没有绑定账本，限制该入口以避免回收成非绑定装备。
- 粮食既是庄园资源又是库存道具，绑定礼包或宝箱获得的粮食继承绑定，只按容量限制后的实际入账数量记账；若库存模板缺失则回滚，保留来源道具。
- 银两、木材等仅有庄园资源余额的资产沿用现有资源账本，不新增资源余额绑定。使用资源礼包获得这些资源属于自用；这些资源余额不具备道具的绑定标记。
- “可丢弃”是允许的规则，本次没有额外新增仓库丢弃按钮。

## 第二轮完整路径复查

| 路径 | 复查结果 |
| --- | --- |
| 入库、批量入库、粮食账本 | 总量与绑定量同时维护，数据库约束；旧库存不回溯绑定 |
| 道具别名合并 | 两份库存的总量与绑定量一起合并；无目标库存时重定向保留原绑定量 |
| 单次自用、批量疗伤 | 优先消耗绑定，包括连续多剂药品 |
| 邮件、全服邮件 | 非法绑定数量在领取前拒绝；缺绑定模板整封回滚；修好配置后可重新领取 |
| 邮件页面、删除保护 | 纯绑定附件显示与领取响应正常；未领取附件不可删除 |
| 系统商店、交易行、拍卖 | 只能扣非绑定；金条同时排除冻结抵押 |
| 帮会捐赠 | 实际扣减及页面可捐数量同时排除绑定、冻结数量 |
| 藏宝阁 | 后端禁止绑定转移；页面数量同时排除绑定与冻结金条 |
| 掠夺 | 只能取非绑定；绑定金条和拍卖抵押均保护 |
| 装备穿脱、替换、重生强制卸装 | 返回保留绑定；已穿戴装备页展示绑定标记 |
| 加工、冶炼、宝箱、灵魂饰品 | 产出道具及粮食继承绑定，生产任务保存输出绑定状态 |
| 募兵 | 只消耗非绑定装备，禁止借阵亡回收洗成非绑定 |
| 门客被俘 | 装备不转移给俘获方；普通门客被俘仍按原战斗规则损失装备，唯一门客退场返还原主保留绑定 |

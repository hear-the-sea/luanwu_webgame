# 侦察报告复查记录

复查目标：检查已定义游戏情景是否有缺漏，并验证词语化后仍保留可用于判断的信息。

结果：已修复发现的信息遗漏与混淆；相关回归测试 468 项通过。代码生成的[参考样式](scout_report_narrative_examples.md)含五档完整报告、五个区域开场及 65 种情景对照。完整[文案规则](scout_report_narrative_design.md)同步更新。

## 情景覆盖

| 维度 | 核对范围 |
|---|---|
| 解锁与区域 | 九个边界等级：0、49、50、99、100、149、150、199、200，与五个区域交叉；预填高档字段也不能提前展示 |
| 门客存在与身份 | 无门客、全归闲、文客独有、武客独有、文武兼备、文武数量分化、身份未知 |
| 品质与境界 | 七个原始品质、文武两类、四阶段两端边界；混合品质、混合境界、少数强者与多数弱者 |
| 待命 | 全待命、全外出、部分待命、状态未知；同品质不同境界及同品质同境界的强者外出／待命对照；可战人数上限 |
| 属性与本事 | 八项属性各阶段与边界、少数强弱、缺项；无技能、寻常、非凡、绝学、混合占比、部分品质未知 |
| 护院 | 无兵、单兵种、五种兵种、少量辅兵、均衡与偏重构成；单一与混合兵种跨成队规模分界 |
| 护院武艺 | 五系、同系多阶段、无武艺、浅／深／满阶、部分资料缺失 |
| 资产 | 四档家底、银多粮少与粮多银少、总粮多但可掠粮少、无可取库存、库存量与估值独立、混合装备品相、材料独有 |
| 可掠口径 | 部分绑定、绑定与受保护库存、可交易筛选、虚拟目标装备保护；计可取份额而非整堆数量 |
| 城防 | 均无、仅墙、仅塔、建设分化、均完善；同建设不同损耗、恢复推算、旧快照缺耐久、一项未知一项已知、异常字段 |

| 表现约束 | 正文隐藏人数、等级与属性数字、技能名与效果、科技名、装备件数；无防守门客栏目；时间元信息保留 |

## 已修复的有用性问题

1. **只突出最强品质会掩盖中间人群。** 现在所有已知品质、境界都有描述，并保留皆、多、部分、少数的区别。
2. **全庄高手不等于当前可战高手。** 待命关联品质与境界，属性和本事按待命状态分组；强者外出与强者待命会产生不同情报。
3. **属性极值与技能最高档会遮蔽短板及占比。** 八项属性保留所有阶段；习得绝学的人多与人少能分辨。已知寻常技能夹杂未知技能，不再断言所学全部寻常。
4. **总粮草不等于可掠粮草。** 分别描述总储备与可掠份额；绑定份额扣除。库藏量、估值与装备品相独立，所有库存文案明确为可取范围。
5. **少数兵种及成队临界会被忽略。** 保留全部兵种与各自规模；同兵种跨关键成队分界时有词语变化，单一兵种也适用。
6. **高深武艺不一定满阶。** 达到科技上限才描述已至圆熟，保留满阶与未满阶差异，仍不泄露科技名或效果。
7. **城防完善不等于城防完好。** 增加采集时实际损耗，使用只读恢复推算；不会因侦察而修复建筑。缺失耐久明确未查明；局部缺失保留其余已知信息。
8. **报告回看不应读取目标当前状态。** 地点、名称、时间与内容使用冻结快照；旧报告保留既有展示行为。

## 验证

- 侦察文案、采集、等级解锁、成功率、任务刷新、通知时区、地图、消息页及保护机制相关测试：468 项通过。
- 针对重要差异使用成对快照断言：同品质不同境界待命、同品质同境界不同实力待命、同库存量不同估值、同总粮不同可掠粮、同建设等级不同损耗、武艺满阶与未满阶、护院跨成队分界。
- 参考样式由当前报告函数直接生成，使用假设快照，不读取真实玩家数据。

## 信息边界

词语分档用于保留规模、构成、强弱、收益与损耗的区别；同档内不同精确数值仍可能使用相同文案，这是隐藏数值的预期结果。

本事只显示已学品质层次，无法据此判断具体招式方向或战术效果。待命表示采集时具备候选出战状态，可同时出战人数受阵容上限约束；不会推断最终参战名单或胜率。报告保留采集时间，后续情况可能变化。

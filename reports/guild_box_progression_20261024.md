# 帮会技能书与装备宝箱分档（2026-10-24）

原配置中，高级技能书箱约26.87%掉蓝书，精研箱约13.70%掉蓝书；紫装、精铸、宗师装备箱全部只掉1件紫装，高阶档的收益差距偏小。

## 调整后的开箱结果

| 科技等级 | 技能书箱 | 装备箱 |
|---|---|---|
| 1～2 | 初级：1本绿书 | 1件绿装 |
| 3～4 | 中级：1本蓝或紫书，约14.15%紫书 | 1件蓝装 |
| 5～6 | 高级：保底1本紫书 | 1件紫装 |
| 7～8 | 精研：独立抽取2本紫书 | 精铸：1件装备，80%紫、20%橙 |
| 9～10 | 宗师：独立抽取3本紫书 | 宗师：独立抽取2件装备，每件70%紫、30%橙 |

宗师装备箱至少获得1件橙装的概率为 `1 - 0.7² = 51%`，有9%概率获得2件橙装。各次抽取允许重复。当前技能书道具最高品质是紫色，因此通过保底品质、书池和数量区分高阶书箱。

橙装池只选用已有常规来源的10种普通橙装，避开蚩尤装备、龙胆枪、龙皇冠及六类任务收集兑换装备。精铸紫装箱的物品键保留，显示名称改为“帮会精铸装备箱”。

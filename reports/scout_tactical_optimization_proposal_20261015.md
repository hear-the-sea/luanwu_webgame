# 侦查报告战术优化方案（待审核）

范围已按用户要求收敛为侦查报告：只在报告中补充战术信息和阵容调整方向，不改出征页面、不增加出征研判接口。

## 目标与现状

让玩家读完能够回答：本次出征主要难在哪里、应该补什么门客和护院、出征前还缺什么条件。

当前版本已经包含候战人手、敌我属性差距、佩装、本事、护院、城防和库藏。主要不足：

- 我方参考按品质、等级挑选空闲主力，不等于玩家本次选定的阵容，也未覆盖所有可替换人选。
- 属性以中位数概括，容易弱化少数危险门客与我方明显短板。
- 本事已有作用分类，但没有将敌方威胁、我方能力缺口和调整建议串起来。
- 护院主要介绍规模与兵种，缺少克制配兵、成队威胁和我方带兵限制。
- 建议依次追加后只取前两条，重要风险可能被前面的泛化建议挤掉。
- 城防损耗建议需要考虑自然恢复，以及连续受攻时开战前回满防守门客和城防的现有机制。

## 表达与阅读顺序

保留探子禀报口吻，默认以定性描述呈现敌情。正文按以下顺序组织：

1. **出征提要**：一句说明主要阻力，再给最重要的一到三项准备动作。
2. **门客研判**：双方长短处、少数突出威胁、适合补足的战斗能力。
3. **护院与城防**：敌方主力兵种、配兵方向、成队风险、城防对交锋的影响。
4. **收益与留守**：可取物资性质、持续作战风险、出征后的守庄空缺。
5. **情报依据**：采集时间、比较对象、尚未查明的关键条件。

报告正文建议控制在约五百至八百汉字；多种风险并存时优先呈现影响出征决定的内容。详细依据另行展开，避免重复陈述人数、品质和修为。

不输出综合战力或胜率；将“存在明确短板”“信息不足”和“已探明的某项优势”分别表达，不合成模糊的必胜倾向。

## 第一阶段：让报告直接给出调整方向

### 1. 建立事实、影响、建议的关联

每条建议内部保存对应事实、适用条件、影响方向与优先级。先解决不可出征和关键情报缺失，再说明明显威胁、阵容调整、收益与留守。

默认选择最多三条互补建议；同一风险合并描述。不能仅因某条建议在代码中生成得早就优先展示。

| 已探明情况 | 报告补充的判断 | 可执行建议 |
|---|---|---|
| 敌方少数候战者明显强于其余人 | 中位水平不能代表全部威胁 | 优先补足承伤、保护或有效控制能力，避免只追求平均属性 |
| 敌方有控制，我方保护或续战能力薄弱 | 关键门客行动受扰时，阵容较难缓冲 | 对照已有技能条件考虑保护或续战人选；仅确认存在有效解控、免控能力时才推荐对应反制 |
| 敌方有回复、减伤，我方只有偏弱的持续输出 | 交锋可能拖长，续战准备更重要 | 补充有效输出或我方续战手段；不由防御高直接推出应该换文士 |
| 敌方多目标伤害，我方多人承伤薄弱 | 多名脆弱门客可能同时受压 | 优先更换明显薄弱者，检查实际可保护队友的本事，不虚构前后排挡伤 |
| 敌方有反震 | 持续受反震可能影响我方续战 | 提醒核对反震适用条件及我方恢复、保护手段，不写“换成多段攻击即可克制” |
| 我方缺少某类应对能力 | 不能假设仓库或门客池里一定有对应资源 | 明确写当前参考人选未见该手段，给出承伤、配兵或暂缓出征的备选方向 |

“偏弱”“薄弱”等判断必须由可复核的比较规则产生。仅有技能作用标签不足以判断强弱，要核对有效对象、触发条件、概率、持续时间及效果；资料不全时降为风险提醒。

### 报告内的具体换人建议

二百级采集时冻结我方参考主力与空闲替补，直接在报告中点明“可考虑以谁替换谁”，说明改善方向以及攻击、承伤、敏捷或带兵能力下降的代价。只使用我方采集时称号，敌方仍按解锁范围定性描述。

保留主要攻击人选、独有本事与唯一队友保护，不推荐明显亏血的候补；无可靠备选时如实说明。低档或历史快照缺少资料时不补猜人选。出征页面不增加任何研判功能。

### 2. 把护院兵种写成配兵建议

复用当前五行克制：刀克剑、剑克拳、拳克弓、弓克枪、枪克刀。

- 例如对方以刀兵为主，可以提示优先考虑枪系护院；同时检查敌方是否有克制枪系的弓兵。
- 我方没有相应兵种或武艺明显不足时，不能只给纸面克制推荐；说明库存、武艺或带兵能力方面的限制。
- 同兵种规模达到战斗规则中的分队攻击门槛时，提示其连续攻击威胁。对外仍用“已成大队”等阶段描述，避免无意提高情报精度。
- 克制影响目标偏好及伤害，不代表每次都能攻击指定兵种。大量混编与集中成队都有代价，不固定推荐平均分兵。
- 报告结合采集时库存与武艺给配兵方向，具体人数由玩家自行配置。

### 3. 更准确地解释行动顺序和城防

- 当前战斗版本普通回合存在护院先于门客的分组顺序，不能笼统写“换高敏门客就能抢在全部敌军之前”。区分普通回合、开战先攻和特殊优先效果。
- 普通目标选择包含随机性，门客偏向攻击敌方门客；不能建议玩家点击指定目标、安排前排吸伤或保证集火某人。
- 城墙侧重说明拦截攻击、延长消耗；箭塔侧重说明额外火力和高阶段多目标威胁。
- 城防残破只代表采集时状态。存在自然恢复与连续受攻回满机制，不将其直接包装成稳定的突破口。

### 4. 收益和代价一起写

- 将银库、可掠库藏、可掠粮与受保护资产继续分开，提醒“仓库估值”不等于“本次一定到手”。
- 可取收益有限且已探明防守较强时，提示求财出征的吸引力有限；不估造净利润和伤亡数字。
- 我方需倾巢出动、缺少可留守人选时，明确指出守庄余量不足。余量是可用人选，不代表其一定会参与后续守战。
- 报告提醒玩家权衡远征占用与留守，实际行军时间沿用原出征流程。

## 解锁和历史报告

| 侦查术 | 新增研判范围 |
|---|---|
| 0–49 | 已知规模、情报缺口与整备提示 |
| 50–99 | 已知兵种的克制方向、成队威胁；不读取未解锁敌方武艺 |
| 100–149 | 候战人数限制、品质修为与留守余量；不生成敌方属性或技能反制判断 |
| 150–199 | 在前述基础上加入可取收益与出征目的的取舍 |
| 200 | 加入属性短板、技能应对、武艺与城防综合研判 |

我方资料可按玩家自己的当前权限展示，但不得用我方信息推导出未解锁的敌方详情。未查明与确认为空分别处理。

新增快照字段采用新版本，已有报告保留原文；新逻辑不能通过读取目标实时数据补齐旧快照。缺失资料时相应分析降级。

## 预期文案示例

以下为最高侦查档位、满足相关事实条件时的假设示例，不表示真实目标状态。

> 庄主，此行应先备足应对刀兵大队的人手。对方虽仅少数门客武力突出，仍有扰乱行动的本事，不宜只看多数人的根底便轻装进取。
>
> 论门客，我方参考主力的承伤与续战手段偏弱。若要进取，宜先补足防护或回气之能，再权衡输出；所学本事能否护及同伴，还须看其作用范围与发动条件。
>
> 论护院，对方以刀兵为主，枪系有克制之利，但还须防其弓兵牵制。宜结合我方枪系武艺与可带兵力配兵，莫只添些零星人手，便指望压住对方大队。对方城墙虽有损耗，也不能据此认定抵达时仍然薄弱。
>
> 若此行为求财，其可取库藏虽有些价值，仍须掂量出兵损耗；若需尽出主力，宜先留妥守庄人手。
>
> 此判断以采集时的候战情形与我方参考主力为据，并非本次选定阵容；出征前仍须自行核对实际人选。

## 实现边界和验收

第一阶段围绕现有快照采集、门客分析、技能识别与禀报生成模块调整，复用战斗规则来源，不复制一套克制表或行军公式。新增建议规则保持纯计算，采集时批量查询，阅读报告不写数据库。

重点验证：

1. 低侦查等级即使混入高阶字段，也不泄露未解锁信息。
2. 改名、升级、换装、归闲或目标变化不会改写已保存报告。
3. 少数强者、大量护院与控制等重要风险不会被泛化建议挤掉。
4. 建议严格对应实际可用能力，不将未知当作没有，不虚构反制机制。
5. 护院行动顺序、分队攻击、城墙拦截和连续受攻恢复与现有战斗规则一致。
6. 同时验证互有长短、能力缺失、无人可战、无合适替补、库存与带兵不足等情形。

全部优化仅在侦查报告中呈现，不增加出征页面联动。

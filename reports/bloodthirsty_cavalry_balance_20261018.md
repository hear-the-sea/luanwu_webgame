# 嗜血铁骑强度审计（2026-10-18）

结论：当前嗜血铁骑属于高基础、低成长的过渡兵。仅解锁时压低科技对手；狼系战斗科技全满后，对普通3级战斗科技顶兵仍有优势，对5级进入明显分化，对满科技顶兵严重落后。如果定位为后期帮会精锐，当前强度和补兵便利性均偏弱。

本次只做读取、离线模拟和报告输出，未调整游戏数值，未连接生产或本地游戏数据库。

## 模拟方法

- 当前工作区代码，正式战斗引擎4、RNG版本1、combat子流，种子从100000开始。
- 总计80,000场，265组参数组合；全部交换攻守，没有超时场。有效回合上限为64。
- 普通L级表示各项个人战斗科技取 min(L, 该项等级上限)，并非帮会“兵法统御”L级；造兵解锁视为已经满足，不影响本次战斗数值。
- 铁骑狼系四维上限5级、狂暴上限3级，显式传入；不会误用普通科技等级充当狼系等级。
- 无装备、护院器械、城防、门客技能、额外属性培养。20门客场景为控制实验，超过默认5人上阵数；5门客场景另行验证。
- 数据来自仓库配置，没有核验线上数据库是否已同步。正常数据库导入器保留弓的负优先级；离线脚本按同一口径恢复原始 YAML priority。
- 攻守两场共用种子，属于配对观测。0%和100%仅指样本结果；不能将攻守合计场数当成完全独立样本计算误差。

## 狂暴与普通特效对照

| 项目 | 实际行为 |
| --- | --- |
| 铁骑狂暴1／2／3级 | 每次分队攻击5%／10%／15%概率触发，最多命中两个不同目标，每个目标各110%／120%／130%伤害 |
| 满狂暴、只有一个目标 | 理论平均增伤4.5%；没有可选第二目标时不会额外再打原目标 |
| 满狂暴、两个等效目标 | 两目标伤害均能完整兑现时，理论平均总增伤24%；过量伤害、反击反伤和目标差异会降低实际收益 |
| 刀系满双击 | 50%概率本次伤害翻倍，理论平均增伤50% |
| 枪系满反击 | 50%概率反击，按受击后最多1000兵有效攻击的30%直接扣血；另有满级攻城+100% |
| 剑系满科技 | 额外开局先攻，先攻倍率100%；反伤比例35%，受正式反伤上限约束 |
| 拳系满科技 | 行动前50%概率恢复当前HP的10%，防守13%；有远程防御与最高30%远程减伤 |
| 弓系满科技 | 两个额外开局行动阶段，其中-2阶段伤害85%；普通近战阶段攻击+100% |

铁骑同样使用每满1000人增加分队攻击的正式规则，冲阵在各分队分别判定。双向不参与1.5倍五行克制，但仍承受枪反击、剑反伤。名称“嗜血”没有对应吸血或自损机制。

科技文案写“追加一次范围冲击”，实装是本次攻击触发时变为双目标并提高伤害，容易让玩家高估成“普攻后再追加”。依据：[铁骑技能构建](../battle/combatants_pkg/troop_builder.py)、[目标选择](../battle/simulation/target_selection.py)、[伤害计算](../battle/simulation/damage_calculation.py)、[普通科技效果](../battle/combatants_pkg/tech_effects.py)。

## 招募与研究性价比

- 铁骑与枪王每人同为1家丁、盘蛇枪／燕羽靴／鲨皮甲／白虹盔／大宛马各1，基础训练300秒。
- 铁骑单次最多20人，枪王满造兵术7级最多350人；招募4000人分别至少200批和12批。该比较是操作批次数，不代表训练时间相差17.5倍。
- 首条帮会路线仅解锁铁骑需20万银、25万粮、12金条、20红宝石；只将解锁＋四维＋狂暴升满，共972万银、1225万粮、220金条、100红宝石，不含狼系其他生产节点。
- 已完成其他路线时，研究资源乘1.2的已完成路线数次方，再逐级向上取整。帮会研究当前即时升级、收益全帮共享；个人每项武艺科技满级基准预算200万银、10天，不能把两种科技视为同时间或同投入。

成本与招募依据：[狼系科技树](../guilds/technology_tree.py)、[科技费用曲线](../guilds/constants.py)、[费用计算](../guilds/services/technology.py)、[招募上限](../gameplay/services/recruitment/recruitment.py)。

## 配置和验证发现

1. YAML回退加载器用safe_non_negative_int读取priority，将弓的-1截成0；正常数据库导入器使用safe_int保留-1。此次离线模拟恢复原始值以匹配正常导入后的数据库规则。该回退差异会影响弓零射程科技结果，未在本次审计中修改游戏代码。
2. build_uniform_tech_levels仅包含个人科技，不自动包含wolf_*；所有铁骑配置已显式设置狼系，避免“满科技”实际上裸兵。
3. 搜索现有测试未发现bloodthirsty_cavalry及wolf_berserk等狼系战斗科技的专门测试。此次模拟使用正式构建器和引擎，另做攻守归属与结果完整性复核。
4. 原始结果的每场数量、胜场、配对攻守胜场、剩余主力、回合和超时计数已检查；全部80,000场无超时。

若目标是低科技阶段共享过渡兵，现有基础强度成立，但招募便利性仍差；若目标是后期特色精锐，应优先重新评估属性科技成长、冲阵机制与器械支持，仅小幅提高狂暴概率很难补齐差距。具体调整值需另外验证，不在本次审计中擅自变更。

- 根目录中符合 `monkey/pig/duck + wen/wu + male/female + 编号` 的 60 张通用图片。

- `pig` 子目录中的 91 张编号猪系图片；逐页检查后按男性形象分类，文武按文件名前缀分类。
- 有人物姓名的专属图片不参加分配。
- 文武和性别为硬性匹配条件；在每一组内按稳定顺序循环分配，组内各图片对应模板数最多相差 1。

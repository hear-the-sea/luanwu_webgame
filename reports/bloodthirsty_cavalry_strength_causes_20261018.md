# 嗜血铁骑强度来源分析（2026-10-18）

后续已落实[高速重骑属性调整与复测](bloodthirsty_cavalry_mobility_20261018.md)。本报告保留调整前的属性与强度结论。

技能展示名称已统一为“铁骑冲阵”。科技节点、等级效果和护院模板描述同步更新，旧数据库模板描述通过新增数据迁移更新，科技标识与已研究等级保持兼容。迁移尚未在游戏数据库执行。

当前强度首先来自一次完整的额外先攻，再由较高四维与冲阵增伤放大。仅取消冲阵不能将铁骑降到“略强”；普通兵种的技能仍有明显价值，铁骑去掉先攻和冲阵后反而低于五系平均。

## 方法与对照结果

使用正式战斗引擎4、RNG版本1的combat子流，只读YAML，dummy数据库后端阻止访问游戏数据库。每个对手使用种子100000—100299，交换攻守各300场。双方分别满科技，无装备、器械、城防或门客技能。

- 纯护院：双方各4000名，分别对战刀圣、枪王、剑圣、拳圣、箭神。
- 混编：双方各1000名护院，搭配相同5名100级橙色门客：项羽、李世民、韦英雄、柴玉关、孔丘。使用属性成长区间均值，无门客技能。
- 每种规则、每种阵容3000场，6种规则合计36000场，另做3000次仅开局阶段的兵力快照。无平局、无超时。
- 所有对照改动只施加在模拟中的战斗单位上，游戏战斗规则与数值保持用户最后指定的版本。

| 对照规则 | 4000纯护院胜率 | 5门客＋1000护院胜率 |
| --- | ---: | ---: |
| 当前规则 | 99.43% | 96.93% |
| 仅移除额外先攻 | 69.70% | 68.37% |
| 仅移除铁骑冲阵 | 93.53% | 83.53% |
| 同时移除先攻和冲阵 | 42.00% | 33.87% |
| 保留先攻、冲阵，仅四维改成满科技枪王 | 82.97% | 87.53% |
| 枪王四维，同时移除先攻和冲阵 | 1.53% | 15.50% |

胜率为五种对手等权平均，按原始胜场数计算。枪王四维对照仅替换攻击、防御、生命和敏捷，不复制枪王反击，不改变铁骑兵种归属。这是属性参照，不能解读为完整枪王镜像对战。

单独取消先攻使纯护院胜率下降29.73个百分点，混编下降28.56个百分点；单独取消冲阵分别下降5.90和13.40个百分点。在当前规则附近，先攻的影响最大。取消两项后的损失远高于单项损失相加，说明二者存在明显配合，不能把这些百分点当作可相加的独立贡献。

## 先攻如何扩大优势

铁骑在优先级-1获得一次完整行动，可触发冲阵并按正式分队规则攻击；没有铁骑专属的先攻伤害折扣。普通回合继续行动。

护院攻击按当前存活人数计算，护院防御也随当前人数的平方根下降。因此先攻造成减员后，对手后续还手伤害减少、承伤能力也下降，铁骑可以带着较多兵力继续攻击。

仅完成所有开局先攻阶段、尚未进入普通回合时，双方初始各4000名的平均存活兵力如下：

| 对手 | 铁骑存活 | 对手存活 |
| --- | ---: | ---: |
| 刀圣 | 4000.00 | 3266.55 |
| 枪王 | 3783.76 | 3402.15 |
| 剑圣 | 3428.03 | 3261.70 |
| 拳圣 | 4000.00 | 3283.23 |
| 箭神 | 3455.55 | 3035.27 |

例如对枪王，进入普通回合前铁骑平均还有约3784名，枪王约3402名；铁骑敏捷18高于枪王16，普通回合还会先行动。枪王反击已实际计入，剑圣反伤和自身先攻、箭神更早的-2阶段也都计入，并非所有对手都无法还手。

## 四维成长与冲阵共同放大先手

铁骑基础攻击24、防御11、生命76、敏捷12。攻击、防御、生命科技每级增加基础值的10%，10级累计+100%；敏捷每级增加基础值的5%，10级累计+50%。这些是基础值加成，不是逐级复利。

| 满科技单位 | 攻击 | 防御 | 生命 | 敏捷 |
| --- | ---: | ---: | ---: | ---: |
| 嗜血铁骑 | 48 | 22 | 152 | 18 |
| 枪王 | 44 | 20 | 144 | 16 |

相对枪王，攻击高9.09%、防御高10%、生命高5.56%，且敏捷领先。更高攻击提高先攻减员，更高生命防御保留己方后续输出兵力。四维降到枪王参照值后，保留两项机制仍有82.97%纯护院胜率；保留原四维但取消两项机制则仅42%。因此当前问题是组合强度，不能归结为四维单独碾压，也不能只调整一个面板数值。

铁骑并非全面敏捷最高：剑圣、拳圣分别为32、38。铁骑不参与普通五系的1.5倍克制，普通兵种缺少针对它的五行增伤；铁骑自身也不获得该克制增伤。枪反击、剑反伤等技能正常生效。

## 为什么每目标70%仍然很强

一整队护院在战斗目标选择中算一个单位。4000铁骑对4000枪王，敌方只有一队，因此冲阵始终使用单目标120%，双目标70%不会作用于该基线。

满级50%触发、未触发普通攻击100%。忽略目标防御差异、暴击和过量伤害，仅比较伤害系数：

- 一个目标：0.5×100%＋0.5×120%＝110%，基础期望提高10%。
- 至少两个等价目标：0.5×100%＋0.5×（70%＋70%）＝120%，基础总伤害期望提高20%，同时覆盖两个单位。

从此前的每目标130%改成当前规则，单目标期望仅从115%降至110%，相对降低约4.35%；两个等价目标的总期望才从180%降至120%，相对降低约33.33%。所以多目标削弱幅度大，但对纯兵对战的影响小。

4000人行动按规则分成5队，每队独立判定冲阵。若5队都能完成攻击，至少一次触发概率为1－0.5⁵＝96.875%。这让技能表现更稳定。分队使用各自人数计算攻击，不是整支4000人重复完整攻击5次；上述高概率也不等于总伤害额外乘5。

## 调整方向

若继续追求“略强于普通兵种”，优先保留先攻这一特色，并给铁骑先攻设置独立伤害系数，降低开局完整行动带来的兵力滚雪球；再检查四维成长，保留有取舍的属性优势。冲阵50%与70%／120%可以先作为固定条件复测。

本次只完成改名和分析，未施加上述平衡建议。招募成本影响普及率和投入成本，不能直接抵消单场等人数对战的优势。

这些实验是等人数控制实验，不是等资源投入、完整玩家配装或线上总体胜率。每个对手600场，100%只代表本次样本全胜；换阵容、门客技能、装备、器械、城防、兵力规模后需要另测。

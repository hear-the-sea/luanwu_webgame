# 绿蓝门客通用图库补齐（2026-10-17）

根据用户最新偏好，鸭系可用于部分负面角色，尽量让每张符合范围的通用图片都得到使用。允许采用卡通化、现代道具表现，不将其解释为角色真实年代的服饰或武器。

## 结果

- 通用图库 177 张，全部用于绿色、蓝色门客。
- 鸭系 5 张全部使用；此前未用的 4 张新增配给 14 个有明确负面事迹的角色。
- 本轮仅调整 35 个模板、17 个 YAML 文件，其余当前匹配保持原样。
- 首轮补图前原本已有头像的 23 个模板继续保留原图。
- 紫色、橙色等其他品质和人物属性不变，未同步线上。
